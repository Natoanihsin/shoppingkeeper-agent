# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-09-19

### Added

- E-commerce dimensional data warehouse
- MySQL metadata knowledge base
- Qdrant field and metric vector retrieval
- Elasticsearch field value retrieval
- Local BGE Chinese embedding model
- LangGraph multi-node NL2SQL workflow
- Intent, keyword and parameter extraction
- SQL generation, validation and correction
- Read-only SQL security guard
- Query timeout and input validation
- Request ID logging and tracing
- SSE streaming progress
- Query cancellation
- React and TypeScript frontend
- Docker Compose one-command startup
- Backend and frontend CI checks

### Security

- Read-only MySQL application account
- SQL AST validation with sqlglot
- Table allowlist
- Dangerous SQL function blocking
- Query row limit
- Environment variable secret protection
