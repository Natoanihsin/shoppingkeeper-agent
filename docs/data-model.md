# 电商问数项目数据模型

## 1. 这个数据库是做什么的

这个数据库用来保存电商订单数据，支持用户用自然语言查询销售情况。

例如：

- 查询某个地区的销售额
- 查询某个商品品类的销量
- 查询某个月的订单数量
- 查询不同会员等级客户的消费情况

## 2. 核心设计思想

这个项目使用的是数据仓库里常见的星型模型。

星型模型通常包含两类表：

- 事实表：记录真实发生的业务事件，比如一笔订单
- 维度表：描述业务事件的背景信息，比如客户、商品、地区、日期

## 3. 本项目中的表

事实表：

- fact_order：订单事实表，记录每一笔订单的销售金额、销售数量等

维度表：

- dim_customer：客户维度表，记录客户姓名、性别、会员等级
- dim_product：商品维度表，记录商品名称、品类、品牌
- dim_region：地区维度表，记录省份、区域、国家
- dim_date：日期维度表，记录年、季度、月、日
